Context

Configure where the widget appears and what it searches.

Where does Context appear?

URL patterns that decide where the widget shows up. Use * as a wildcard, e.g. https://github.com/*/issues* or https://*.atlassian.net/browse/*.

Where does Context take you?

Each destination becomes a button in the widget and a right-click menu item. Use {term} as the placeholder in the URL template. Choose Salesforce componentDef as the encoding to build a base64 Lightning search payload — then use a template like https://YOUR-INSTANCE.lightning.force.com/one/one.app#{term}. Icons are just characters — paste any emoji (try ⌘ + Ctrl + Space on Mac or Win + . on Windows) or any symbol from emojipedia.org.

Keyboard shortcuts

Click a shortcut field and press a key combo to record it. Shortcuts require at least one modifier key (⌘, ⌃, ⌥). Click ✕ to clear. Per-destination shortcuts grab highlighted text and search immediately.

Backup

Settings (sources + destinations) and remembered searches back up separately so you can share your config without leaking the terms you've searched. Import auto-detects which kind of file you picked.
