Context

Configure what Context searches. Summon it anywhere with a keyboard shortcut.

Where does Context take you?

Each destination becomes a button in the widget and a right-click menu item. The first four also get quick-search slots — highlight text on any page and press the slot's shortcut to search immediately. Use {term} as the placeholder in the URL template. Choose Salesforce componentDef as the encoding to build a base64 Lightning search payload — then use a template like https://YOUR-INSTANCE.lightning.force.com/one/one.app#{term}. Icons are just characters — paste any emoji (try ⌘ + Ctrl + Space on Mac or Win + . on Windows) or any symbol from emojipedia.org.

Keyboard shortcuts

Shortcuts are managed by Chrome (chrome://extensions/shortcuts) so they work on every page without Context needing access to any site. Quick-search slots map to your first four destinations, in order. On macOS, if ⌘M is taken by window-minimize, rebind the toggle shortcut there.

Backup

Export your destinations to a JSON file to share or move your config between machines.
